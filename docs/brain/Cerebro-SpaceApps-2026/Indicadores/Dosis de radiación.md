# Dosis de radiación

- **Peligro:** [[Radiación espacial]]
- **Fuente de datos:** dosímetro autónomo a bordo (ejemplo real: [[CSA - CANS]]).
- **Medidor acumulado:** % del límite de carrera de **600 mSv** usado + proyección de cuándo se alcanzaría.
- **Tasa diaria según entorno** ([[Selector de entorno]]): crucero a Marte 1.8 mSv/día · superficie de Marte 0.67 mSv/día ([[Curiosity RAD]]).
- **Evento solar (SPE):** 🔴 alerta inmediata → refugio de tormenta, cuenta regresiva, pasos. Límite a corto plazo: 250 mSv.
- **Conexiones:** al tocar "Radiación" se iluminan corazón, ojos (cataratas) y sistema inmune.
- **Justificación:** las Academias Nacionales recomendaron que cada astronauta conozca su exposición actual y lo que representa.
