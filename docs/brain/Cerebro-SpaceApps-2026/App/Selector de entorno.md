# Selector de entorno

El reto sugiere considerar distintos entornos. El selector cambia el contexto de cada recomendación.

| Entorno | Retraso de comunicación (un sentido) | Tasa de radiación | Nota |
|---|---|---|---|
| Estación (ISS) | ~instantáneo | Menor | Evacuación posible en horas ([[Crew-11 - primera evacuación médica]]) |
| Nave en tránsito a Marte | Hasta 20 min | 1.8 mSv/día | Ingravidez ~6 meses |
| Superficie de Marte / base | Hasta 20 min | 0.67 mSv/día | 1/3 de gravedad |
| Base lunar | ~1–2 s | Intermedia | Meta de base para 2032 |
| Rover | Según la base | Según el blindaje | Lejos del refugio |

Ejemplo de mensaje: "En Marte, la respuesta del médico puede tardar hasta 40 minutos ida y vuelta; sigue este protocolo mientras tanto."
