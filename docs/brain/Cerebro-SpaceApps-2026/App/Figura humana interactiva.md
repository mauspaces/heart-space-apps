# Figura humana interactiva

Pantalla principal (sugerida textualmente por el reto). Cada zona es clicable y se colorea 🟢🟡🔴.

| Zona | Indicadores | Riesgos HRP |
|---|---|---|
| Cerebro | [[Sueño y luz]], [[Ánimo, estrés y diario]], test de reacción | Conductual, sueño, equipo |
| Ojos | [[Visión (SANS)]] | SANS |
| Oído interno | [[Equilibrio y mareo]] | Sensoriomotor/vestibular |
| Corazón y pulmones | [[Presión arterial]], [[Frecuencia cardíaca y HRV]], SpO₂ | Cardiovascular, hipoxia |
| Sangre y metabolismo | [[Glucosa]], [[Nutrición e ingesta]] | Nutrición |
| Riñones | [[Hidratación]] | Cálculos renales (vía hueso) |
| Sistema inmune | [[Temperatura]], [[Síntomas]] | Inmune, microorganismos |
| Huesos y músculos | [[Ejercicio, hueso y músculo]] | Hueso, condición física |
| Todo el cuerpo | [[Dosis de radiación]] | Cáncer por radiación |

## Al tocar una zona
1. Qué hace ese órgano (explicación simple)
2. Estado actual + tendencia
3. Qué peligros lo afectan y por qué ([[Cinco peligros]])
4. Qué hacer: acción inmediata, prevención, cuándo escalar
5. "Cómo medir" paso a paso
